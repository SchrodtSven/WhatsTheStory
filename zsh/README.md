# zsh

## Cursor Movement

- <kbd>Ctrl + A </kbd> - go to begin
- <kbd>Ctrl + E </kbd> - Go to end

### Del, cut & remove

- <kbd>Ctrl + U </kbd> - Delete from cursor position to start
- <kbd>Ctrl + K </kbd>- Cut from the cursor to the end of the line.
- <kbd>Ctrl + W </kbd>- Cut from the cursor to the start of the preceding word.
- <kbd>Alt + D </kbd>- Remove from the cursor to the end of the next word.
